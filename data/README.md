# Data source

Project dataset: **IBM HR Analytics Employee Attrition & Performance**.

- Dataset page: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
- Direct ZIP download: https://www.kaggle.com/api/v1/datasets/download/pavansubhasht/ibm-hr-analytics-attrition-dataset
- Expected CSV filename: `WA_Fn-UseC_-HR-Employee-Attrition.csv`

The dataset is fictional and was created for analytics practice. It contains 1,470 employee rows and 35 source columns. It must not be presented as IBM's real workforce data.

Do not commit the downloaded CSV to a public repository unless you have reviewed and accepted the source platform's current terms. The project code and documentation can be published without the raw CSV.

The source has no dates. Therefore, this project does not invent monthly attrition trends, forecasts, hire dates, or exit dates.

`MonthlyIncome`, `DailyRate`, `HourlyRate`, and `MonthlyRate` do not have a documented currency in the source. Display them as numeric units without adding a currency symbol.
